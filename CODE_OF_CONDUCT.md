# Code of conduct

Recode welcomes technically grounded contributions from people with different experience levels.

Be respectful in issues, pull requests, and code review. Discuss behavior and evidence rather than attacking contributors. Do not harass, threaten, discriminate against, or disclose private information about others.

Disagreement about design and implementation is expected. Explain trade-offs, respond to questions in good faith, and keep feedback specific to the work.

AI-assisted contributions are allowed under the same review requirements as other contributions. Criticize the code when necessary, not assumptions about how it was written.

If you experience unacceptable behavior, contact the repository maintainer through a private GitHub channel when available. Do not publish personal information in a public report. The maintainer may remove abusive content, lock conversations, or restrict participation when necessary.

These expectations apply to repository discussions, issues, pull requests, and other project-managed spaces.
